# Apollo Server on EC2

A small GraphQL server used to explore Apollo Server, TypeScript code generation and deployment on AWS EC2.

## Project goal

Build and deploy a typed GraphQL service while learning the infrastructure steps required to run a Node.js process on a virtual machine.

## Features

- Apollo GraphQL server
- Typed schema and resolvers
- GraphQL code generation
- Production TypeScript build

## Technologies

- **TypeScript**
- **Node.js**
- **Apollo Server**
- **GraphQL Code Generator**
- **AWS EC2**

## What I learned

- Building a standalone Apollo Server
- Generating TypeScript types from a GraphQL schema
- Compiling a service for production
- Deploying and running Node.js on EC2

## Running locally

```bash
npm install
npm run codegen
npm run start:dev
```

## Project status

This is a learning and experimentation repository. It documents the concepts practiced at the time and is not presented as a production-ready application.
